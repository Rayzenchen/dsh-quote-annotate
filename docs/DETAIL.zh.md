# 对话引用批注

![对话引用批注图标](../icon.svg)

在对话里选中一段文字，点选区旁的「＋ 添加到输入框」：原文变成输入框里的引用芯片，输入框上方
出现一张批注卡；写下评论、按回车收起，发送时插件把「原文 + 评论」变成一段中文结构化文字交给
模型——模型看到的是逐条批注，而不是一段出处不明的引用。

## 为什么用它

- **引用有出处**：每条批注都带被选中的原文；公式、表格、代码块按 Markdown 源码引用，模型能逐条对上。
- **评论不丢**：普通消息发送时，批注块由引用芯片的 codec 序列化，评论永远跟着原文走。
- **斜杠命令也能用**：命令消息和批注一起发时，插件把它自动拆成两条——先发命令（如 `/计划`），
  再把批注消息作为第二条发出。
- **原生引用保留**：只隐藏选区旁的原生「引用」按钮；原生引用块和消息里的 `> ` 预览照旧。

## 怎么用

1. 在对话正文里选中一段文字（输入框、侧栏里的选区不生效）；
2. 点选区旁的「＋ 添加到输入框」；
3. 在输入框上方那张批注卡里写评论（Shift+回车换行，回车收起卡片）；
4. 按回车发送——模型收到的是一条带前言、编号、`> ` 原文和 `我的批注：` 的结构化消息；
5. 想改：点输入框里的芯片，卡片会重新打开；点卡片上的 ✕ 移除这条引用。

多条批注会按草稿里的顺序编号；已发送消息里的批注块会折叠成「引用批注 N 条 · 展开」徽标，
点开可以当场核对。

## 斜杠命令：一次回车，自动拆成两条

命令只认草稿里的纯文本，芯片在命令参数里会退化成被选中的原文、评论丢失；DSH 也没有公开接口
能把批注直接塞给命令。所以插件这样做：一次回车 → 先以空参数发送命令（`/计划` 只进入 plan 模式，
不发消息）→ 命令结算后把批注消息重建出来，作为普通消息自动发出。

如果草稿里还有别的来源的引用芯片、DSH 原生引用块或附件，插件重建不了，会拒绝并提示你先单独
发送命令——草稿和芯片全部原样保留。

## 隐私与边界

- 全部功能在浏览器侧完成；宿主半边是空的，只为让客户端名册加载这个包。
- 不修改 DSH 源码，只使用公开的输入机座位、槽与引用源接口。
- 选区内容与评论只存在本机会话台账里，随消息发出。

## 安装

```sh
dsh plugin --profile <profile> add github:Rayzenchen/dsh-quote-annotate#v1.0.0
```

或从本地目录：`dsh plugin --profile <profile> add /path/to/dsh-quote-annotate`。
装完刷新页面即可（功能全在浏览器侧）。

## 兼容性

在 DSH `0.2.3-alpha.2` 上验证；`engines.dsh` 声明 `>=0.2.3-alpha.2 <0.3.0`。DSH 的槽与座位
契约没有官方兼容承诺，升级后建议跑一次 `node tools/verify-core.mjs`，并实测一条带批注的消息。

## 验证

```sh
node --check index.js && node --check client.js
node tools/verify-core.mjs      # 275 项断言
```
